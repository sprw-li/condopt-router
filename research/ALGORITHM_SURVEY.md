## 0. 选型速查（先看这里）

### 0.1 决策表

| 场景特征 | 首选 | 次选 | 不建议 |
|---|---|---|---|
| 连续变量，d≤10，预算 30–200，单目标，噪声中低 | **GP-BO + logEI/qEI** | TPE（d≤20 且分类占比高） | 纯随机（浪费预算但可作基线） |
| d>20 连续 | **TuRBO 式局部 GP-BO** 或 GP + 维度缩放 lengthscale 先验 [R15] | CMA-ES | 全局 GP-BO（GP 拟合不稳、采集优化病态） |
| 分类/条件变量 ≥30%，空间树状 | **TPE** [R4] / **随机森林代理 + EI（SMAC）** [R7] | GP + one-hot 松弛 [R13] | 纯 GP-ARD（one-hot 高基数时严重过拟合） |
| 预算很小（≤20）且有历史相似任务 | **暖启动/迁移代理** [R16] + GP-BO | TPE + 人工先验点 | CMA-ES（冷启动差） |
| 离散选择很多（>50 水平，如溶剂库） | **描述符/特征化 + GP**（Gryffin 思路） | TPE categorical | one-hot GP |
| 噪声很大（CV>20%）或不可重复 | **qNEI/qNEHVI + 重复测量聚合** [R10][R12] | 加重复的 TPE/CMA-ES | 确定性 EI（会把噪声当信号） |
| 可并行 batch（≥4）| **qEI/qNEI 贪心** [R3] 或 **TS 采样** | 局部惩罚（local penalization） | 串行 EI 浪费并行器 |
| 多目标（2–3）| **qNEHVI** [R12] | ParEGO [R11] | 加权求和固定权重（凸性丢失） |
| 有昂贵约束 | 约束 GP + `EI×PoF` / qNEHVI-constrained [R10] | 罚函数 + 可行性过滤 | 只优化目标后筛除（可能全不可行） |
| 有多保真（模拟/小试/中试）| **多保真 GP（保真度作为输入）+ cost-aware 采集** | BOCA（离散保真） | 只在最高保真上采（浪费低成本信息） |
| 空间是"配方/流程/程序"而非向量 | **LLM 提议 + 数值评估**（FunSearch/LLAMBO 范式）[R19][R20] | 人工编码成向量后 BO | 硬套 GP |

### 0.2 速查规则（经验法则，写进 router 的默认策略）

1. **初始化预算**：`n0 = max(5, min(20, 2*(d_eff+1)))`；昂贵的实验用 `n0=8–12`，别把 >40% 预算花在初始设计上。
2. **总预算**：BO 相对随机搜索的显著优势通常在 `n ≥ 20–30` 后才出现；`n < 15` 时随机/ LHS + 领域先验更划算。
3. **d_eff**（有效维度）比原始维度更关键：大量变量对目标无影响 → 用 ARD/稀疏先验或先做筛选。
4. **永远跑一个随机/LHS 基线**：Bergstra & Bengio 已证明超参调节中随机搜索因低有效维度而意外强；报告增益必须相对它。
5. **采集函数优化失败（多起点结果分散）是 BO 崩坏的第一信号**，而非 GP 拟合。

## 1. 问题形式化与空间类型学

### 1.1 形式化

最大化（或最小化）黑箱 `f: X → R^m`，`m=1` 单目标、`m>1` 多目标，带 `c(x) ≤ 0` 约束、保真度 `s ∈ S`、批量 `q`：

```
max_{x∈X} E[f(x)]  s.t.  P(c(x) ≤ 0) ≥ 1-δ,  cost(x,s) ≤ C
```

观测模型（最常见）：`y = f(x) + ε`, `ε ~ N(0, σ²(x))`；化学实验中 `σ(x)` 常随 `y` 增大（乘性噪声），此时对 `y` 取 log 再用同方差 GP 更合理。

### 1.2 变量类型与编码（**实现时最容易踩坑的地方**）

| 类型 | 例子 | 编码 | 解码/约束 | 坑 |
|---|---|---|---|---|
| 连续 | 温度 20–120 °C | 原始值（建模前 z-score） | — | 物理量纲差异大 → 必须归一化，否则 ARD 初始化失效 |
| 正尺度/乘性 | 浓度 0.001–1 M | **log10 变换**后当连续 | 变换回原空间 | 跨越多个数量级时不 log，GP 会在小值端几乎不分辨 |
| 整数 | 当量数 1–5、转速 200–1200 | 连续松弛 `[l,u]`，采集优化后 round；或直接离散枚举 | `round` 后 clip | 取整会重复采样；建议对取整结果去重后再去重预期收益 |
| 分类（无序） | 溶剂、催化剂、配体 | one-hot（低基数 ≤10）；**描述符特征**（≥10 水平） | argmax → 原类别 | one-hot 让 GP 认为类别间等距；高基数把维度炸开 |
| 有序分类 | 温度档位 low/mid/high | 整数编码 0/1/2 + 单调先验 | — | 当纯 categorical 编码会丢失顺序信息 |
| 条件/层级 | "若溶剂=A 则温度范围不同"；"加料顺序" | **条件参数**：只在父参数取某值时激活；建模时把未激活维度用哨兵值/子空间处理 | 采样时按条件 mask | 统一 GP 对未激活维度会学到伪相关；建议按分支训子模型或使用树代理 [R7] |
| 组合（子集/排列） | 配方中选 3 种添加剂；加料序列 | 位向量 / 排列编码 / 描述符聚合 | 投影到合法集 | 合法性约束（如互斥）必须在解码器强制 |
| 文本/配方 | "配体 SMILES" | 指纹/描述符向量 或 LLM 提议 | — | 指纹高维稀疏 → GP 需降维/预训练嵌入 |

**三条工程原则**

- **单一编码层（encoder/decoder 成对存在）**：算法只看 `[0,1]^k` 连续张量，空间层负责 encode/decode + 合法性投影 + "去重已评估点"。参考 BayBE 的 `Parameter`/`SearchSpace` 设计 [R17]、SMAC 的 `ConfigSpace` 条件约束 [R7][R8]。
- **category 低基数用 one-hot + 每维独立 lengthscale（ARD）**：让 GP 学到"哪个类别的差异重要"。高基数（>10）改用描述符（溶剂：介电常数、极性、沸点…）或分组嵌入，这是 Gryffin 的核心思想（"专家知识特征化 categorical"）。
- **整数/离散的采集函数优化**：优先在**离散候选集上枚举**（可行集 ≤10⁵ 时直接打分取最大，精确且无近似误差），不要"连续优化后取整"了事；只有连续占主导时才用 round 投影。

### 1.3 有效维度与空间剪枝

- 先做**敏感度排序**（一次 LHS 设计 + 方差分析 / 随机森林特征重要性），把明显无关的维度钉死或加零方差先验。
- 变量间有硬约束（如 `T + P ≤ 常数`）时，用**可行域投影**：采样后拒绝/投影到约束面，或参数化为 `x = A·z + b`（线性约束）。
- **不要一开始就全维 BO**：先固定次要变量做 1D/2D 扫描，把预算花在有交互的维度上（这是化学家的工作流，也是 router 应该支持的"分阶段空间收缩"）。

## 2. BO-GP 核心（默认主力）

### 2.1 GP 建模（数值细节决定成败）

**模型**：`f ~ GP(m(x), k(x,x'))`；默认 `m(x)=0`（观测先去均值），核函数用 **Matérn ν=5/2 + ARD**：

```
k(x,x') = σ_f² · (1 + √5 r + 5/3 r²) exp(-√5 r),  r = sqrt(Σ_i ((x_i-x_i')/ℓ_i)²)
```

ν=5/2 对平滑但非无限可微的实验响应最稳；ν=1/2（指数核）适合阶跃/相变；RBF（ν→∞）常过平滑，**不推荐**做默认。

**超参先验（工程默认，按作者经验 + BoTorch 默认量级，落地时以所选库版本文档为准）**

| 超参 | 推荐先验 | 说明 |
|---|---|---|
| lengthscale ℓ_i | `Gamma(3, 6)` 或 `LogNormal(0, 1)`；高维用 `LogNormal(√2+0.5·ln d, √3)` [R15] | 后验集中在远大于 1 时说明该维无关（或需换核） |
| outputscale σ_f | `Gamma(2, 0.15)` / HalfNormal(1) | 与 y 的标准化耦合，y 标准化后较稳定 |
| 噪声 σ_n | `Gamma(1.1, 0.05)`（BoTorch 默认量级）；**有重复测量时直接估**：`σ_n² = 组内方差均值` | 化学实验噪声常异方差 → 对 `log y` 建模或加 input-dependent noise |
| 均值 | 0（y 标准化后） | 有先验知识时用线性均值/物理模型输出作 mean function（便宜且强） |

**预处理标准流程**（照抄即可）

1. 输入：连续维 → 归一化到 `[0,1]`（min-max）；正尺度维 → 先 log10 再归一化。
2. 输出：`y ← (y - μ_y)/σ_y`；若乘性噪声且 `y>0`：`y ← log(y)` 再标准化（注意别对可能为负的目标做 log）。
3. 噪声：有重复点 → 用组内方差做已知噪声（`alpha` = 噪声方差/σ_y²）；无重复 → 让 GP 从边际似然学噪声，并加先验防过拟合。
4. 建模式选择：`n < 3d` 时**冻结超参为默认值**（最大化边际似然会过拟合），或使用 MAP + 强先验；`n > 5d` 时再放开优化。
5. 检查：拟合后看 `ℓ_i` 是否撞边界、训练残差是否 ~0（说明噪声先验过小）、后验方差是否在数据外合理增大。

**降复杂度**：`n>2000` 用 inducing points（SGPR/VFE，m≈256–512）或 TuRBO 局部化；实验场景 `n<500` 一般用精确 GP 即可。

### 2.2 采集函数：公式 + 选择 + 参数

记 `μ(x), σ(x)` 为后验均值/标准差，`f*` 为当前最优（最小化时取最小），`z = (f*-μ)/σ`（最小化），`Φ, φ` 为标准正态 CDF/PDF。

**(a) EI（Expected Improvement）—— 默认首选** [R1]

```
EI(x) = (f* - μ) Φ(z) + σ φ(z)       （最小化）
      = σ [ z Φ(z) + φ(z) ]
```

- **数值稳定**：σ→0 或 z 很负时用 log-space 实现（`log EI`），否则下溢成 0 导致采集函数处处为 0、优化器乱走。BoTorch 已提供 `qLogEI`。
- **参数**：无（只有 `f*` 的选择）。`f*` 用**观测最优**而非后验最优；有噪声时用"后验最优估计"或 `qNEI` 的内层 baseline。
- **失效**：探索不足（初期几乎总选 μ 高附近）；大批量 q 时 greedy 会扎堆 → 用 qEI 或局部惩罚。

**(b) PI（Probability of Improvement）**：`PI = Φ(z)`。过度利用、探索极差，**只作为对照**。

**(c) UCB/LCB**：`UCB = μ + κ σ`。`κ` 固定 2.0–2.5 可用，但强依赖尺度；GP-UCB 理论给出 `β_t = 2log(t^{d/2+2}π²/(3δ))`。**适合需要显式控制探索程度**的场景；噪声大时 μ 不可信 → 降 κ。

**(d) Thompson Sampling（TS）**：从后验抽一条函数 `f̃ ~ GP`，在其上求 argmax（可用随机傅里叶特征近似采样，或 BoTorch `MaxPosteriorSampling`）。**并行天然友好**（每 batch 点独立抽一条），实现简单，是 qEI 的廉价替代；缺点是方差大、可复现性依赖 RNG。

**(e) qEI（并行 EI）** [R3]

对 `q` 个候选点 `X = {x_1..x_q}`，联合后验下：

```
qEI(X) = E[ max(0, max_{i=1..q} f(x_i) - f*) ]
```

- **实现**：Monte Carlo——从 `q` 维联合正态抽 `S` 组样本（S=128–512），每组算 `(max_i f_i^s - f*)_+`，取平均。BoTorch：`qExpectedImprovement` / `qLogExpectedImprovement`。
- **批量选择策略（关键）**：
  1. **贪心 + 条件化（sequential greedy，默认）**：先优化 `q=1` 的 EI 得到 `x_1`，把它"幻想"进模型（Kriging believer 用后验均值；**constant liar** 用当前最优 `f*`），再优化 `x_2`… 优点：稳、便宜；缺点：顺序贪心可能错过联合最优。
  2. **联合优化**：在 `q×d` 维空间直接最大化 qEI（`optimize_acqf` 的 `sequential=False`）。q≤4 且 d≤8 可用；q 大时维度灾难。
  3. **循环坐标上升（cyclic）**：固定其余点、轮流优化每个 `x_i`，几轮即收敛（`optimize_acqf_cyclic` 思想）。q≥8 时的实用折中。
  4. **离散候选切分**：从 Sobol 候选池里选 q 个（组合优化：贪心 + 交换），适合 categorical/整数为主的空间。
- **参数**：`q`（batch 大小）、`num_samples`（S，越大越准越慢；q 大时 128–256 足够）、`num_restarts`（2–10）。
- **注意**：qEI 的 MC 估计在高斯下无偏但有方差 → 固定 RNG seed 以保证可复现；q≥10 时 MC 方差显著，考虑准 MC（Sobol 点做采样）或改用 TS。

**(f) qNEI（Noisy EI）** [R10 相关 + BoTorch]

`qNEI(X) = E_{f|D}[ max(0, max_i f(x_i) - max_j f(X_baseline)_j ) ]`，把 `f*` 也当作随机变量（对 baseline 点做嵌套 MC），从而**正确处理噪声**——不会因为一个幸运的高观测值而停止探索。

- **参数**：`X_baseline`（建议 = 已评估点；`n>200` 时抽样或 `prune_baseline=True`）、内外层样本数（64–256）。
- **何时必须用**：重复测量 CV 大、点间噪声不等、或 `max(y)` 明显是运气时。**推荐把它做成噪声场景的默认**，而不是 EI。

**(g) MES / PES（信息型采集）**：最大化"对最优值/最优点的信息增益"。少样本时比 EI 探索更有效，但实现复杂、计算贵。**只在极低预算（n<20）+ 高维**时考虑，第一版可不实现。

**(h) 采集函数通用失效信号**：多起点优化后各起点收敛到不同区域的 EI 差异 <1e-3 → 多半是 GP 后验方差塌陷（超参错误/重复点过多），换鲁棒采集（qNEI/TS）或重置 GP。

### 2.3 采集函数优化（Acquisition Optimization）

- **连续空间（默认）**：L-BFGS-B，多起点。起点 = `raw_samples`（Sobol 采样 256–4096 个）中按采集值取 top-k（k=10–20），每起点约束到 bounds 内；或用 `scipy.optimize.differential_evolution` 兜底。**记住解析梯度**（GP 核函数可微，手推或自动微分；numpy 手写比 autograd 快）。
- **候选池方法（混合/离散空间首选）**：生成候选集（Sobol 10⁴–10⁵ 或"已评估点邻域 + 随机"），解码到合法空间，一次性算采集值取 max。优点是**无需梯度、天然处理整数/分类/约束、可去重**；缺点是分辨率受池大小限制（10⁴ 个点对 5 维够用，10 维以上要 10⁵）。
- **混合空间**：连续维用梯度优化 + 离散维用候选枚举，交替上升（block coordinate）；或直接全候选池。
- **约束下优化**：可行域已知（线性/边界）→ 投影到可行域；可行域由代价可接受的约束函数给出 → 采样时拒绝不可行；约束也昂贵 → 用约束 GP 的 `P(feasible)` 进采集函数（见 §9）。
- **停止条件**：`num_restarts` 内最优值与 top-3 均值差 < 1e-4·σ_y → 判定收敛，减少 restart。

### 2.4 BO-GP 默认参数表（可直接写进 config 默认值）

| 参数 | 默认 | 范围 | 备注 |
|---|---|---|---|
| kernel | Matern52 + ARD | {Matern52, Matern32, RBF} | 先 5/2，出现阶跃换 3/2 |
| 初始点 n0 | `max(5, min(20, 2*(d_eff+1)))` | 5–30 | ≥ d+1 才可拟合 |
| acquisition | `logEI`（低噪）/ `qNEI`（有噪） | {logEI, qEI, qNEI, UCB, TS} | 噪 CV>10% 直接 qNEI |
| batch q | 1（串行）/ 并行器孔位数 | 1–16 | q 大用 cyclic |
| num_restarts | 10 | 2–20 | 预算紧用 5 |
| raw_samples | 512 | 128–4096 | 高维加到 4096 |
| MC samples S | 256 | 64–1024 | q 大时降 S 加 restart |
| 超参优化 | MAP（强先验）/ MLE | 3 档 | n<3d 冻结先验 |
| 噪声处理 | 已知重复方差 or 学 σ_n | — | 有重复必用 |

### 2.5 BO-GP 失效模式（排障清单）

1. **GP 拟合信息不足**（n ≤ d）：后验方差巨大/超参乱跳 → 先用 LHS/TPE 攒点。
2. **重复点**：实验里"同样条件做两次"会让 `K` 奇异 → 用噪声项正则（`alpha`）或合并重复观测（推荐后者，方差已知）。
3. **核函数不匹配**：响应有阶跃/阈值（相变、溶解极限）→ Matérn 5/2 过平滑，换 3/2 或加指示特征。
4. **量纲/尺度没归一化**：表现为 lengthscale 极端（一个 1e-6 一个 1e3）。
5. **异方差**：高收率区噪声大 → 对 log(y) 建模，或用 input-dependent noise（`HeteroskedasticSingleTaskGP`）。
6. **采集优化病态**：采集函数在边界/重复点附近出现尖峰 → 用 logEI + 候选池 + 去重。
7. **过度探索**：qEI 在 q 很大时总选边界 → 局部惩罚或 TS。
8. **高维失效**：d>20 且 n<10d → 换 TuRBO/局部化或 CMA-ES [R5][R14]。
9. **约束太紧**：可行域 <5% 体积 → 先做可行性建模（分类 GP），或分两阶段"先找可行、再优化"。
10. **数值错误**：y 全是常数/近乎常数 → 先查数据，别硬跑。

## 3. TPE（Tree-structured Parzen Estimator）[R4]

### 3.1 算法核心

不用 GP，而是直接对"好的点"和"坏的点"建两组密度，最大化密度比 ≈ 最大化 EI。

对每个候选 `x`：`l(x) = p(x | y < y*)`, `g(x) = p(x | y ≥ y*)`，其中 `y*` 是观测的 `γ` 分位数（`γ = p(y<y*)`）。可以证明：

```
EI(x) ∝ ( γ + (1-γ) · l(x)/g(x) )^{-1}
```

所以只需**最大化 `l(x)/g(x)`**（在 log 空间比，避免下溢）。

### 3.2 实现要点（必须搞对的细节）

1. **分位数 γ 怎么取**：论文/ hyperopt 传统用 `γ=0.25`（即"前 25% 的点算好点"）。Optuna 默认更精细：`γ(n) = min(25, ceil(0.1·n))`，即 `n≤250` 时取 10%，之后固定取 25 个点。**建议**：`γ = clamp(round(0.15n), 5, 25)`，并在 `n<10` 时退化为随机采样（`n_startup`）。
2. **`l/g` 的实现**：对每维独立建 KDE（`l` 用"好点集"、`g` 用"坏点集"），取 log 后相加比较。**不要**用比值（数值不稳）。
3. **带宽**：数值维用自适应带宽（hyperopt 用"样本量缩放的 Parzen + 高斯先验混合"，`adaptive_parzen`）；简单实现可用 Scott/Silverman 规则 + 乘 0.5–1.0。**带宽过小 → 只会在已有点附近重复采样**；过大 → 退化为先验采样。
4. **先验的作用**：KDE 与先验混合（如 `p = (1-w)·KDE + w·prior`，w≈0.1–0.3 或按样本量衰减），保证初期与尾部有覆盖。分类维：`l/g` 用各级别频率 + 拉普拉斯平滑；数值维：先验取参数范围上的均匀或高斯。
5. **候选生成**：从 `l` 中抽 `n_EI_candidates`（默认 24）个候选，逐个算 `l/g`，取最大者。**注意从 `l` 抽而不是从空间均匀抽**（效率差一个量级）。
6. **分类/条件空间**：每维独立 → 天然支持任意树状条件空间（"未激活维"不参与密度）；这是 TPE 相对 GP 的最大优势，也是**混合/条件空间默认选它**的原因。
7. **并行**：constant liar——把 pending 点的 y 填成当前最差（或最优），重算 `y*` 后再采样。有专门工作改进 TPE 的并行（"batch TPE"）。
8. **退化保护**：`n<10` 或 `l` 的支持集 <3 个点 → 返回随机/LHS 点；`l` 与 `g` 完全分离（log 比 >20）时仍要保留 5% 概率随机点防早熟。

### 3.3 参数/失效模式

| 项 | 建议 |
|---|---|
| `n_startup` | 10（Optuna 默认） |
| `γ` | 0.15–0.25，或 Optuna 的 `min(25, ⌈0.1n⌉)` |
| `n_candidates` | 24（默认）；空间大时 64–128 |
| 带宽 | 自适应/规则 + 先验混合 |

**失效**：① 维度 >30 且点稀疏 → KDE 全塌缩到先验（"TPE 退化为随机"）；② 强相关变量（如两个溶剂参数）→ 独立 KDE 学不到交互；③ 数值维跨数量级没 log → 带宽失真；④ 样本 <10。**修复**：降维/特征化、按相关变量分组、log 变换、或换 SMAC 的森林代理 [R7]。

## 4. CMA-ES / 进化算法 [R5]

### 4.1 什么时候用

- 维度高（d>20–50）、预算相对多（上千次评估，或评估便宜）、响应崎岖/不平稳/有相变。
- 空间是**纯连续或"可松弛"的混合整数**；对纯 categorical 不友好（除用 one-hot + 修复）。
- 需要**全局多峰**搜索：CMA-ES 的重启策略（IPOP/BIPOP）是标准解法。
- 作为 BO 的对照基线/兜底：**router 必须保留"采样器在 N 次内没改进 → 切 CMA-ES/随机"的 fallback**。

### 4.2 关键参数（标准 CMA-ES，照公式实现即可）

```
λ = 4 + ⌊3 ln n⌋            # 每代采样数
μ = ⌊λ/2⌋                   # 精英数
w_i ∝ ln(μ+0.5) - ln i,  Σw=1,  μ_eff = 1/Σw_i²
c_σ = (μ_eff+2)/(n+μ_eff+5)
d_σ = 1 + 2·max(0, sqrt((μ_eff-1)/(n+1)) - 1) + c_σ
c_c = (4+μ_eff/n)/(n+4+2μ_eff/n)
c_1 = 2/((n+1.3)²+μ_eff)
c_μ = min(1-c_1, 2(μ_eff-2+1/μ_eff)/((n+2)²+μ_eff))
```

- `σ0`：**取搜索区间的 25–30%**（如 `0.3·(u-l)`），不要用 1.0（尺度错误会让前几十代浪费）。
- 边界：简单 clip 会扭曲分布；更稳的是**在超界时反射/重采样**（Hansen 的建议），或加二次罚函数。
- 停止：`TolFun`（f 变化 <1e-12）、`TolX`（σ·max|p| 小）、条件数 >1e14；**多峰必须加重启**（IPOP：失败后 λ 翻倍；BIPOP：交替大小 pop）。
- 噪声：**用更大 λ**（λ=16–64）或"每个点重复评估 k 次取均值"；CMA-ES 对中等噪声稳健，极大噪声会漂移。

### 4.3 混合/离散扩展

- **整数变量**：MI-CMA-ES（对整数维做"取整 + 方向修正"）；简单做法：连续松弛 + 取整 + 若取整后重复则扰动重采样。
- **分类变量**：one-hot 编码 + 采样后修复到 one-hot（argmax 投影）；或把 categorical 作为"选择算子"（GA 式交叉/变异）与 CMA 混合。
- **纯离散/排列**：改用 GA/DE/模拟退火，或用 LLM 提议（§12）。
- **CMA-ES 的 BO 混合（最实用）**：BO 全局失效后，用 CMA-ES 在"BO 推荐点邻域"内做局部精修；或反向：CMA-ES 探索 → BO 利用。

### 4.4 失效模式

- 目标噪声极大且不可重复 → 协方差被噪声主导，早熟收敛到错误方向（加大 λ/重复测量）。
- 维度 >100 且预算 <1000 → 协方差矩阵学不出来（用 separable CMA / diagonal 版本）。
- 分类占比高 → one-hot 松弛失真（换 TPE/SMAC）。
- 需要严格可行性 → 罚函数要足够大，否则大量点不可行（先投影到可行域）。

## 5. 随机与低差异序列（初始设计 + 基线 + 候选池）

### 5.1 方法对照

| 方法 | 实现 | 优点 | 缺点/注意 |
|---|---|---|---|
| 纯随机 | `np.random.uniform` | 无假设、可并行、无偏 | 覆盖差，小样本易聚簇 |
| LHS [R6] | `scipy.stats.qmc.LatinHypercube(d, scramble=True)` | 每维分层，边缘覆盖好 | 高维下"每维 1 点/层"退化为随机；categorical 要手动分层 |
| Sobol | `scipy.stats.qmc.Sobol(d, scramble=True)` | 低差异、可增量、可估积分 | **点数最好取 2 的幂**；d>20 后低差异优势衰减；必须 scramble 才能做无偏统计 |
| Halton | `scipy.stats.qmc.Halton(d, scramble=True)` | 简单、可任意长度 | 相邻维相关（尤其高维）；不 scramble 会明显偏差 |
| 网格 | `np.meshgrid` | 完全可解释 | 维度灾难（5 维 × 10 点 = 1e5） |

### 5.2 实用建议

1. **初始设计默认 Sobol（scramble=True）+ 解码**：连续/整数都好用，且天然是"随机化的"可复现（固定 seed 即可）。
2. **categorical 分层**：对每个 categorical 维按 `n_levels` 做"尽量均衡"的分配（LHS 思路），确保每个类别都出现 ≥1 次；水平数 > 样本量时，优先放"领域先验最优"的类别 + 少量探索类别。
3. **点数**：`n0 = max(5, min(20, 2*(d_eff+1)))`；Sobol 想凑 2 的幂就取最近的 8/16/32。
4. **候选池**：采集函数优化的候选池用 scramble 后的 Sobol 10⁴（d≤10）～10⁵（d≤20），比均匀随机覆盖更好且便宜。
5. **基线对照**：任何新算法上线前，与"随机搜索 + 相同的初始点"比较；用随机搜索做显著性检验的下界。
6. **不要用未 scramble 的 QMC 做 Monte Carlo 估计**（会引入偏差）；只用于空间填充。

## 6. Bandit / 分类变量 / 早停与预算调度

### 6.1 Bandit 视角

- **多臂 bandit**：当每个"条件"其实是有限个离散选择（如 6 种催化剂）且评估噪声大时，UCB/Thompson Sampling 比 BO 更稳（BO 在小离散空间上等于昂贵版的 bandit）。
- **算法选择本身是 bandit 问题**：router 维护"算法 × 问题特征"的收益表，用 TS/UCB 在 TPE/GP-BO/CMA-ES/随机之间动态选（这就是本项目的 skill router 的算法层）。上下文 = (d, n, 噪声估计, categorical 比例, 剩余预算)。
- **早停/预算调度**：
  - Successive Halving / Hyperband [R? 下轮编号]：对"多保真"（如反应时间短/长、底物用量少/多）按 `η=3` 逐轮淘汰，`s_max=⌊log_η(R)⌋`。
  - **BOHB** = Hyperband 的预算调度 + TPE 的配置采样；在"能早停的反应条件"（短时间试跑判决）上非常省。
  - **ASHA（异步 SH）**：并行器不等整轮，先完成的先晋级——化学实验流水线天然异步，值得实现。

### 6.2 分类变量的四种处理（按基数选）

| 水平数 | 方法 | 说明 |
|---|---|---|
| ≤5 | one-hot + GP-ARD | 最简单，可解释 |
| 6–20 | TPE / 森林代理（SMAC） | 避免维度爆炸与伪距离 |
| 20–100 | 描述符特征（溶剂物性/指纹）→ GP | Gryffin 思路；把"类别相似性"变成"物理相似性" |
| >100 或复合对象 | 预训练嵌入 / LLM 提议 + 数值评估 | 见 §12；或聚类后分层 bandit |

- **化学特有**：溶剂/配体这类 categorical 有**丰富的现成描述符**（介电常数、Hansen 参数、位阻、pKa…）——**优先用描述符替代 one-hot**，这是本项目相对通用 HPO 库的最大增量点。
- 互斥/组合约束（"两种溶剂不能同时用"）→ 在解码器强制，别让模型去学。

## 7. 多目标（MOO）

### 7.1 路线一：标量化 + 单目标 BO（ParEGO 型）[R11]

- 每轮从单纯形采权重 `λ ~ Dirichlet(1)`，用**增广 Tchebycheff** 标量化：
  `g_λ(f) = max_i(λ_i · f_i) + ρ · Σ_i λ_i f_i`，`ρ = 0.05`（经典取值，用于保证弱 Pareto 最优被偏好）。
- 优点：复用单目标 BO 全部机制（EI、约束、多保真），实现成本最低；对 2–3 目标稳。
- 缺点：每轮只朝一个方向，Pareto 前沿覆盖靠随机权重；噪声大时不稳定。
- **实现建议**：保留最近 k 轮的 λ 与其最优点，避免同一方向重复采样（或对 λ 加"未覆盖方向"偏好）。

### 7.2 路线二：EHVI 型 [R12]

- 定义超体积 `HV(P)`（给定参考点 `r`），采集 = `E[HV(P ∪ {f(x)}) - HV(P)]`。
- **qEHVI**（2020）：MC 估计并**可微**，支持 q 个点联合；**qNEHVI**（2021）：对 baseline 集合也 MC 积分，解决**噪声**问题（推荐默认）。
- 参数/实现要点：
  - `ref_point`：取"比最差值再差一点"（如 `nadir - 0.1·range`）；**参考点选择直接影响优化行为**，必须根据业务目标设定（例如收率<30% 视为无意义，则 ref 取 30%）。
  - 2–3 目标：EHVI 便宜，优先用。
  - >3 目标：超体积计算指数爆炸 → 用 MC 近似/标量化 + 多目标进化（NSGA-II/MOEA/D + 代理）。
  - 约束多目标：qNEHVI 支持 `constraints` 参数（可行性作为乘子）。
- **噪声多目标下"Pareto 集"本身是随机的**：报告时要给"概率 Pareto 集"（如 ≥80% 置信的支配关系），不要只给点估计。

### 7.3 路线三：多目标进化（NSGA-II/III、MOEA/D）+ 代理

- 评估便宜或预算大时直接跑；评估昂贵时用"代理辅助进化"（每代用 GP 预测 + 不确定性采样）。
- 适合 >3 目标（NSGA-III 的参考点法、MOEA/D 的分解法）。

### 7.4 多目标验收

- 指标：`HV`（固定 ref point）、`IGD`、Pareto 集规模/覆盖；报告方差（多 seed）。
- 陷阱：不同算法用不同 ref point 时 HV 不可比；跨实验比较必须**固定 ref point 与目标缩放**。

## 8. 批量 / 异步并行

### 8.1 三种批量策略

| 策略 | 原理 | 适用 | 成本 |
|---|---|---|---|
| **qEI 贪心/循环** | 联合后验下最大化 q 点 EI，逐点条件化 | q≤8，质量优先 | 中（每点一次采集优化） |
| **TS 批量** | 每点独立抽后验样本求 argmax | q 大、要快 | 低 |
| **局部惩罚 local penalization** | 在单点 EI 上乘一个"离已选点太近就降权"的惩罚项 | q 很大（>8）、廉价 | 很低（单点 EI + 惩罚） |

- **局部惩罚公式（概念）**：`acq_batch(x) = EI(x) · Π_j [ 1 - exp(-(L·||x-x_j||)²/(2σ_j²)) ]` 形式的"高斯尾概率"，其中 `L` 为 Lipschitz 常数估计（用 GP 后验最大梯度或核长度尺度估计），`σ_j` 为 x_j 处后验标准差。实现时直接用"距离核"近似即可：`penalty = 1 - exp(-||x-x_j||²/(2ℓ_pen²))`，`ℓ_pen` 取 lengthscale 的 0.5–1 倍。**这个简化版在实验场景足够好**。
- **Kriging believer / constant liar**：按序给"幻想点"赋伪观测（后验均值 / 当前最差），再重算采集。constant liar 更保守（鼓励分散），believer 更快但可能扎堆。
- **异步（真实实验流水线）**：pending 点必须进入模型（作为"未知 y"），否则会重复推荐；实现：pending 队列 + "去重半径"（变异系数/欧氏距离阈值）+ 每完成一个点重算一次推荐。

### 8.2 批大小选择

- 并行器 q 大（≥8）时，**串行质量下降**明显（贪心偏差）；建议 q≤8 用 qEI，q>8 用 TS 或 local penalization + q=1。
- 关键是"batch 内多样性"：加约束"任意两点距离 ≥ 0.1·范围"通常比换算法更有效。

## 9. 约束优化

### 9.1 约束分类与处理

| 约束类型 | 例子 | 处理 |
|---|---|---|
| 简单箱约束 | 温度 20–120 | 优化器 bounds |
| 线性/几何可行域 | 配方总和=100% | 参数化投影（simplex 变换） |
| 便宜可计算约束 | 溶解度模型可算 | 采样后过滤 / 投影 |
| 昂贵黑箱约束 | 需要实验测的"是否分层/是否安全" | **约束 GP + 可行性概率** |
| 噪声约束 | 重复测量才知的"纯度≥95%" | 见 §9.2（Letham 方法） |
| 硬安全边界 | 爆炸极限 | 保守代理 + 大 margin，不交给优化器 |

### 9.2 采集函数层融合

- **EI × PoF**（经典、简单）：`acq(x) = EI(x) · Π_j P(c_j(x) ≤ 0)`。每类约束一个 GP（分类用 GP 分类/概率回归）。
- **推荐做法（噪声场景，Ax 的路线 [R10]）**：对约束的**带噪观测**建模（不是把约束当确定性），用"截断后验"的 EI；至少要做"约束值的重复测量聚合"，否则 `P(feasible)` 会剧烈震荡。
- **q 批量 + 约束**：`qEI(X) · Π_i,j P(c_j(x_i) ≤ 0)`；qNEHVI 已内置约束支持。
- **可行性优先策略（可行域很小的时候）**：前 30% 预算只优化"可行性"（采集 = PoF 或"距可行边界距离"），找到可行区后再优化目标——这比一开始就乘积更容易成功。
- **不可行点的保留与利用**：不可行样本并非无用——约束 GP 需要它；但**目标 GP 是否要用不可行点**要慎重（通常在目标 GP 里排除，或加指示特征 `feasible`）。

### 9.3 实现要点

1. 约束值可能跨数量级 → 同样做标准化；`c(x) ≤ 0` 的符号约定统一。
2. `P(feasible)` 用高斯 CDF：`Φ(-μ_c/σ_c)`；σ_c→0 时要平滑化，否则梯度为 0。
3. 采集优化时**先用候选池过滤不可行**（若约束便宜），能显著加快。
4. 报告时同时给"最优点"和"P(feasible)"，让化学家判断风险。

## 10. 多保真（Multi-fidelity）

### 10.1 两条主流路线

1. **保真度作为连续输入**（连续近似，Kandasamy 2020）：把 `s∈[0,1]` 拼进 GP 输入，核在 `(x,s)` 上定义（`s` 方向单独 lengthscale 往往更长），采集时按"单位成本的信息/改进"选 `(x,s)`。实现最简单，**推荐第一版**。
2. **BOCA（离散保真 + 多模型）**：每个保真度一个 GP，共享先验/超参；用"互信息/成本"选点。适合 2–4 个明确档位（模拟/小试/中试）。

### 10.2 关键实现细节

- **成本感知采集**：`acq_cost(x,s) = acq(x,s) / cost(s)^α`，`α∈[0.5,1]`；`α=1` 即"每单位成本收益"，实验里常用。
- **保真度之间的关系**：默认"偏差单调"（低保真系统性偏低）；在 GP 里用 `s` 的均值函数处理偏差（如加 `β(s)` 的线性项），比纯零均值稳。
- **不要过度用低保真**：低保真与真值相关性 <0.7 时，多保真收益可能为负（存在误导）。上线前先做"仿真-实验相关性"小样本验证。
- **批量**：先低成本大批量筛选（如 96 孔短反应），再对 top-k 做高保真验证——这本身就是一种简单的多保真 + 批量策略，无需复杂算法。
- **注意**：化学里"保真度"常不是单调标量（不同测试条件不是"精度"关系）→ 更稳妥的建模是**把测试条件当成输入维**（如反应时间 1h/24h 都是输入），而不是"保真度"参数。

## 11. 迁移 / 元学习 / 暖启动

### 11.1 可用的迁移形式（按成本从低到高）

1. **先验点/暖启动**：把历史 campaign 的最优点（或相似体系的最优点）作为初始设计，再跑 BO。成本最低、收益不稳但几乎无风险（只需保证不重复）。
2. **超参先验迁移**：从历史任务学 lengthscale/outputscale 的分布，作为新任务的先验均值（MAP 初始化）。实现：预训练一次，存 `prior_mean_of_log_lengthscales`。
3. **代理集成（Wistuba 2018 [R16]）**：为每个历史任务训练 GP，按"在目标任务已观测点上的似然"加权合成预测；对负迁移有自适应淘汰机制。成本中等，效果好于简单拼数据。
4. **多任务 GP / 元学习**：共享核/深度核/context 变量；数据要求高，第一版不推荐。

### 11.2 工程要点

- **相似度判定**：按"空间重叠度 + 变量语义 + 目标定义"分组（化学里 = 同一反应类型/同一催化剂体系）；不要跨反应类型硬迁移。
- **数据对齐**：历史数据的单位、目标定义（收率 vs 转化率）、噪声水平必须统一；不一致的先分层。
- **负迁移防护**：迁移只影响**先验/初始化**，不让历史数据进入似然；在线监测——若前 n0 个点的相对改进低于随机基线，自动丢弃迁移先验（router 可做这个决策）。
- **可复现**：记录"用了哪些历史 campaign、权重多少"到 run metadata。

## 12. LLM / agent 驱动优化（本项目的"router"层）

### 12.1 三种已经验证的范式

1. **LLM 作为 BO 的增强件（LLAMBO [R19]）**：LLM 读"变量名+取值范围+历史"，产出：①冷启动初始点；②采集函数候选（替代 Sobol 随机候选）；③对目标/可行性的经验性先验。**GP 与数值采集函数仍然负责最终决策**——这是目前最稳的组合。
2. **LLM 直接当优化器（OPRO 范式，待编号）**：把"历史 (x, y) 轨迹"放进 prompt，让 LLM 提议下一批 x；适合空间是**文本/配方/流程**或语义强相关的条件（如"选一个更亲核的溶剂"）。缺点：没有不确定性量化、成本高、可复现性差（同 prompt 不同 seed 差异大）。
3. **LLM 演化程序/构造（FunSearch [R20]）**：维护"候选程序库 + 岛屿模型"，LLM 做变异/交叉，evaluator 打分入库。适合"输出是配方/流程/规则"的场景，与数值 BO 互补。

### 12.2 本项目 router 的建议架构（算法选择 + 参数配置）

```
输入：空间描述(JSON schema) + 历史数据 + 预算/并行度/约束 + 领域元信息
 ↓ (1) 规则层（确定性，永远先跑）
   d>20 → TuRBO / CMA-ES；categorical>30% → TPE/SMAC；n<15 → LHS+先验；噪声大 → qNEI
 ↓ (2) LLM 层（可选，输出结构化 JSON）
   在候选算法集里选 1–3 个 + 给出空间变换建议（log? 描述符?）+ 失效诊断
   → 必须用 JSON Schema 校验 + 白名单 + 兜底默认值（LLM 不许改数值超参太多）
 ↓ (3) 数值算法层执行 ask/tell；每轮把 (状态, 诊断) 回传，LLM 可选地调整策略（低频，如每 10 次评估）
```

**给 LLM 的上下文要包含**：变量类型与量纲、已评估点数、当前 best、噪声估计、上轮推荐是否被执行/是否失败、算法当前"健康指标"（GP 拟合残差、采集优化多起点一致性、改进停滞轮数）。

**必须有的防护**：①结构化输出 schema 校验；②LLM 只在白名单算法/参数范围内选择；③LLM 调用失败/超时 → 规则层默认；④LLM 建议的"空间变换"要过数值检查（如 log 只能用于正值域）；⑤记录 prompt + 输出到 run history（可复现/可审计）。

### 12.3 失效模式

- LLM 编造不存在的最优点/历史（幻觉）→ 所有数值必须来自程序上下文，不来自 LLM 记忆。
- 上下文过长导致"忘记"约束 → 把关键约束放在 prompt 末尾 + 结构化字段。
- 成本：每轮调用 LLM 的成本可能接近一次实验成本，**只在决策点调用**（如每 5–10 次评估一次）。
- 可复现性：固定 temperature（建议 0–0.3）、记录完整 prompt 与模型版本。

## 13. 失效模式总表（排障时的索引）

| 症状 | 最可能原因 | 处置 |
|---|---|---|
| 推荐点反复重复/扎堆 | 去重缺失、pending 未进模型、EI 尖峰 | 去重半径、pending 队列、logEI/TS |
| 一直在边界采样 | 采集函数过度探索（q 大、κ 大） | 减 q、局部惩罚、约束到内点 |
| 早熟收敛（不再改进） | GP 后验方差塌陷、超参过拟合 | 重置 GP、加噪、换 TS/qNEI |
| 改进停滞但后验方差很大 | 采集优化失败（局部最优） | 加 restart/候选池，检查梯度实现 |
| 分类变量总选同一类 | one-hot 距离失真/过度利用 | 描述符化、TPE、加探索 |
| 约束后几乎无可行点 | 可行域太小/约束建模错 | 两阶段（先可行性）、检查符号/单位 |
| 噪声大时 Pareto 集乱跳 | 未做噪声处理 | qNEHVI、重复测量、概率 Pareto |
| 高维下 GP 不收敛 | d 太大/点太少 | TuRBO、降维、CMA-ES |
| 迁移后反而变差 | 负迁移 | 只迁移先验、监测丢弃、按反应类型分组 |

## 14. Benchmark 与验收（实现完算法后必须先建这个）

1. **基准集三层**：
   - 合成函数：Branin、Hartmann-6、Rosenbrock、Ackley、Levy（连续）；离散版用"one-hot 嵌入 + 取整"。
   - 化学 emulator：Olympus 数据集 [R18]（HPLC、Fullerenes、Suzuki、SnAr、Photocatalysis）——含真实噪声，最接近本项目。
   - 项目内真实/半真实数据：历史 campaign（带重复测量）。
2. **指标**：best-so-far 曲线（主）、simple regret、达到阈值所需评估数、多目标用 HV/IGD、并行场景用"墙钟时间内 best"。
3. **协议**：固定 seed 集（≥20），相同初始设计，**相同总评估数**；报告 IQM + bootstrap 95% CI（不要只报均值）；跨算法比较用固定 ref point。
4. **噪声**：每个配置至少重复 3 次；报告"结果方差"本身是产品价值的一部分。
5. **回归门槛**：新算法/新采样器必须 ≥ 基线（随机搜索）在 ≥70% 的基准上不劣化，才能进 router 候选集。
6. **在线监控**：真实 campaign 中记录每次推荐的"预期改进 vs 实际改进"，用于校准 router 的算法选择。
